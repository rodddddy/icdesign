    2Gates & specifications

    Choose gate types and allowed input counts: 2, 3 and/or 4 inputs, all selected by default. Click a gate name to toggle its specs. INV always has 1 input; multi-input XNOR inverts XOR parity.

    Multiplexing uses the selected basic gates, not a MUX cell. SR latches require the matching NAND or NOR gate type. Edge-triggered circuits require D flip-flops; these stay selected even with Select none.
