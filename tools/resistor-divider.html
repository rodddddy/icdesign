How it works

  • Each tap is placed so that the resistance below it divided by the total resistance is as close as possible to k = VREF / VTARGET.
  • With switches, one tap is taken straight out and every other tap closes a switch that shorts a block below it, so its ratio comes from fewer unit resistors; the solver picks which tap stays plain. Switches sit at the tap or below it — never next to VIN, which may be a high-voltage node.
  • Only one switch is closed at a time, selected by a one-hot SEL bus: with w switches, the bus is SEL<w:1> (or plain SEL for one switch), each switch is driven by one bit shown to its right, and each tap lists the full bus code that selects it. Each switch state changes the total resistance, so the solver accepts a solution only if every state stays inside the allowed resistance range.
  • Every segment uses identical unit resistors Ru: n in series, plus optional series groups of p units in parallel (Ru/p each).
  • The trip error is the relative shift of the actual trip voltage VREF / k from the target voltage.
  • Among the solutions found within the tolerance, the one with the fewest unit resistors is selected first, then the one with the fewest switches.
  • The search uses nearby tap positions, sampled total resistances up to 2000 Ru and bounded combinations of parallel groups. It does not enumerate every series / parallel network or guarantee a global optimum.
  • Comparator input current, resistor mismatch, voltage and temperature coefficients and contact or wiring resistance are not included.
